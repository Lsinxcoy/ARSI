# ARSI — Autopoietic Recursive Self-Improvement

自创生递归自我改进系统。融合 Autopoiesis、MetaRSI 与 Mental World Modeling 的统一架构。

## 核心理念

> 一个自创生系统，它的改进回路本身必须是自创生生产的；而它对自身联合世界状态（物理+心智）的建模质量，决定了这个自我生产过程的质量。

## 架构

```
┌─────────────────────────────────────────┐
│  不可变层（G1-G10 铁律）                  │
├─────────────────────────────────────────┤
│  自创生 Governor                         │
│  输入: S_t = (Φ_t, Ψ_t)                  │
│  输出: a = (a_phy, a_ment)               │
├──────────┬──────────┬───────────────────┤
│ 赋能引擎  │ SIWM     │ 梦境管道           │
│ 九维度    │ 世界模型  │ 自我模型刷新       │
├──────────┴──────────┴───────────────────┤
│  Mnemosyne 统一记忆底座                   │
│  SELF / EXPERIENCE / PROXY 三区隔离       │
├─────────────────────────────────────────┤
│  密封评估器（在所有写掩码之外）            │
└─────────────────────────────────────────┘
```

## 快速开始

```bash
# 安装依赖
pip install -e ".[dev]"

# 运行测试

python scripts/baseline_eval.py
```

## 核心模块

| 模块 | 职责 |
|------|------|
| `foundation/` | 数据模型、存储引擎、铁律执行器 |
| `mnemosyne/` | 统一记忆底座（三区隔离 + 记忆代理） |
| `world_model/` | SIWM 世界模型（η + MindZero + 行为预测器） |
| `governor/` | 自创生 Governor（决策 + 维度管理） |
| `empowerment/` | 赋能引擎（九维度 + 四级验证） |
| `pipelines/` | 七管器官（梦境管道等） |
| `sealed_eval/` | 密封评估器（系统不可读） |

## 设计原则

1. **绝不盲标 SUCCESS** — 无证据的赋能操作必须标 UNKNOWN
2. **铁律不可被改进改写** — G1-G10 是所有自创生过程的不动点
3. **三区隔离** — 自我记忆 / 经验记忆 / 代理记忆权限分离
4. **信号新鲜度 = η** — 自我模型失配度是连续生理指标
5. **维度轮换进化** — 每个 term 重点进化 2-3 个维度，不是全部
